# 本地验证范围

本次源码交接没有进行GPU39新实验，也没有在任何非英伟达计算卡上运行推理。下列测试已在当前容器中分组执行，使用CPU、合成状态和fake-native；不是真实计算卡性能测试。

| 测试组 | 数量 | 本地结果 |
|---|---:|---|
| 交接/数据导出/计划/参数检查 | 30 | 通过 |
| 原实验编排、准入修复、五方法原生路径与确认案例 | 121 | 通过 |
| 原semantic19 DAG/数据/执行测试 | 31 | 通过 |
| 原typed19输入/父响应/质量/原生路径 | 53 | 52通过；1项依赖历史结果的测试明确跳过 |
| 原精简打印/归档侧车测试 | 30 | 通过 |
| 合计 | 265 | 264通过，1项结果文件专用测试跳过 |

被跳过的是`test_refusal_signal_not_quality_rewrite`，它直接读取未交付的`analysis/received_results.json`，不属于算法或响应解析路径。没有用假历史文件替代。原数据正文不在上传源码包中，导出器在本地用明确标注的合成输入测试；真实GPU39数据哈希和ZIP最终导出须在源服务器执行。

同时核对了48项原应用/原生源码身份、9个wfsched核心文件、13个关键算法/应用保护文件；原12个相位模型及4个副本默认模型系数与去诊断元数据后的系数完全相等。

本地解释器为Python 3.13；源服务器使用Python 3.11。控制端要求Python 3.11+，具体目标serving/SDK的Python兼容性由目标平台验证。CPU测试能运行不代表原vLLM hook已经适配目标驱动或内部API。

未声称已完成的内容：目标卡native hook正确性、目标卡缓存/时钟/队列语义、目标校准模型有效性、真实应用质量或任何性能收益。
